# Sample images

Three unmodified images from the validation split of the MMOTU OTU_2d dataset
(Zhao et al., "MMOTU: A Multi-Modality Ovarian Tumor Ultrasound Image Dataset for
Unsupervised Cross-Domain Semantic Segmentation", https://github.com/cv516Buaa/MMOTU_DS2Net),
included so visitors can try the app. They are not used for training.
